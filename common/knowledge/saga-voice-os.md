# Deepgram Saga — Voice OS for Developers

Deepgram Saga is a **Voice Operating System (Voice OS)** for developers — it is NOT a speech-to-text model or a text-to-speech model. Saga is a separate product from Nova, Aura, Flux, or the Voice Agent API.

## What Saga Is

Saga is a desktop application that lets developers control their entire development workflow using natural voice commands. It connects to and coordinates across multiple developer tools — GitHub, GitLab, Jira, Linear, Slack, terminal, Cursor, Replit, Windsurf, and more — through a single unified voice interface.

**Example:** Say "Find logs related to that payment failure and show me the API calls" → Saga automatically searches terminal logs, extracts timestamps, opens network data, and presents a correlated timeline — without typing.

## What Saga Is NOT

- Not a speech-to-text API (that is Nova-3, Nova-3 Multilingual, Flux)
- Not a text-to-speech API (that is Aura-2)
- Not the Deepgram Voice Agent API (that is for building voice agents into your own apps)
- Not available as an API — it is a downloadable desktop app

## Key Features

- **Cross-tool coordination:** Execute commands across Git, Jira/Linear, terminal, Slack in sequence with one voice prompt
- **Vibecoding:** Use voice to drive AI coding tools like Cursor, Replit, Windsurf without prompt engineering
- **No window switching:** Execute commands without leaving your current screen
- **Command line without typing:** "Run integration tests and notify me if anything fails"

## Results (from Deepgram)
- 60% faster PR reviews
- Automatic standup reports
- Seamless multi-project management
